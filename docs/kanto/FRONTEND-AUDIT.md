# Frontend audit — KANTO (formerly LOVA)

Date: 2026-11-22. Scope: the React frontend in `apps/frontend/`, its Git history, the parallel branches, the LOVA Figma file and the contracts the frontend must honour. This audit was written before any product code changed, as the brief requires. The product was renamed from LOVA to KANTO during this session; the rename is listed in [Renaming](#renaming-lova--kanto).

Companion documents: [FIGMA-COVERAGE.md](FIGMA-COVERAGE.md) (frame by frame), [FRONTEND-ROADMAP.md](FRONTEND-ROADMAP.md) (prioritized backlog), [API-INTEGRATION.md](API-INTEGRATION.md) (contracts, mocks and adapters), [MVP-DEMO.md](MVP-DEMO.md) (demo path and what is real).

Findings:

- **FE-01 and FE-02 are not on `develop`.** PR #94 removed shidoAdr's provisional shell to hand it to FE-01, so `develop` has no home, no gallery and no router. The complete frontend only exists on the feature branches.
- **The most complete code was uncommitted.** The integration refactor (26 staged deletions, 31 untracked files) lived only in a worktree of a second local clone. It passed its checks, so it was adopted as the base (see §2).
- **Two local clones exist**, both on `feature/home-gallery`, identical. Work continues in one of them. The copied `.claude/worktrees/` folders inside it are stale duplicates, excluded from Git by `.git/info/exclude`.
- A stash on `feature/frontend-init` ("pending: record endy-rkt approvals") holds documentation edits only. Left untouched.
- The root `npm run lint` failed with 2 559 errors before this session, all from files that are not part of the product: the Draco decoder copied into `apps/frontend/public/draco/` by the `copy-draco` script and the stale `.claude/worktrees/` copies. Both are now in the ESLint global ignores (root config change, flagged for endy-rkt).
- `apps/frontend/README.md`, `docs/motion.md` and `docs/verification.md` (commit `0e32341`) and the UX-01 journey (`36e0cd2`) were not on the integration branch. Both commits were cherry-picked onto the new branch.

## 2. Base chosen for KANTO

Branch `feature/kanto-frontend`, created from `feature/gallery-integration` (`3c07d69`), then:

1. the uncommitted integration work copied from the worktree and committed as `305ef89`;
2. the frontend docs commit `0e32341` and the UX-01 journey `36e0cd2` cherry-picked;
3. Prettier applied to the one file it flagged (`ImmersiveGallery.tsx`).

Checks on this base (Node 26.13.1 locally, Node 22 in CI): `npm run typecheck -w apps/frontend` OK, `npm run test -w apps/frontend` 105 tests in 17 files OK, `npm run build -w apps/frontend` OK (chunks: index 369 kB, three 716 kB, model-viewer 442 kB, ImmersiveGallery 276 kB, all lazy except index), `npx eslint apps/frontend` OK once `public/draco/` is ignored.

Nothing from the previous branches was deleted. `feature/home-gallery`, `feature/gallery-3d` and `feature/gallery-integration` keep their history.

### Design tokens and typography

`styles/tokens.css` mirrors the Figma variables (`--color-ink #0e1116`, `--color-paper #f0ece4`, `--color-gold #c8a174`, `--color-wine #67271f`, `--color-accent #7e2a20`, spacing, radii, shadows, wall gradients, `--u` = one Figma pixel of the 1440×900 stage). Fonts: New Icon Serif and Helvetica Now Display are licensed and gitignored (present locally in `public/fonts/licensed/`); OFL fallbacks Instrument Serif, Instrument Sans, Bebas Neue and Averia Serif Libre are committed.

### Media and 3D assets

- Paintings (public domain, three sizes each) and the valiha track live in the gitignored `public/media/` and are present locally.
- Three CC0 Poly Haven models (`ceramic_pot`, `antique_ceramic_vase_01`, `wooden_bowl_02`, 1K glTF + textures + poster) are present locally under `public/media/models/`. They are study objects, labelled "hors collection" in the notice. The user confirmed they may be used in the 3D object sections.

- No rights-cleared Malagasy scan exists in the repository. The 3D-01b Reality Composer scan (4.9 MB USDZ, 148 kB 2K GLB) is held by shidoAdr outside Git.

## 5. Figma vs code: notable differences

- The Figma rooms show 12/08/06/10 works per room; the code has 4 paintings and 3 study models. Content, not code.
- Figma notice (128:56) has "Observer de près" and "Œuvre suivante" actions and a "Œuvre de démonstration · contenu fictif" badge; the code has both actions and a demo note.
- Figma "Observer de près" (128:152) has a mini-map, a zoom slider with percentage and "Ajuster"; the code's `CloseUpViewer` has zoom and pan, to compare in the browser during validation.
- Figma wordmark is a thin Didone "LOVA"; the code draws it as an SVG path. KANTO needs a new wordmark.

## 6. Contracts the frontend must honour

- **Frozen Gate 0 contract** (`docs/agents/parallel-workflow.md` on develop): `GET /api/items`, `GET /api/items/:id`, `POST /api/items`, `POST /api/items/:id/media`, `POST /api/items/:id/review`, `POST /api/items/:id/mint`, `GET /api/items/:id/provenance`, `GET /api/items/:id/model3d`; `PublicationStatus`, `ClaimStatus`, public errors `{ code, message, requestId }`, 3D `{ contentId, status: ready|processing|missing, variants: { poster, glb1k, glb2k } }`, mint `pending|confirmed|failed` with an idempotency key.
- **Auth contract proposal** (`docs/specs/auth-contract.md`): `POST /auth/register`, `POST /auth/login`, `POST /auth/logout`, `GET /auth/me`, HttpOnly cookie session, error codes `VALIDATION_FAILED`, `INVALID_CREDENTIALS`, `SESSION_INVALID`, `EMAIL_ALREADY_REGISTERED`, `AUTH_UNAVAILABLE`.
- **LiDAR contract** (`docs/api/lidar.yaml`): display `{ contentId, status: ready|none, variants: { '1k', '2k' }, poster, ar: null }` and file delivery under `/api/lidar/files/{assetId}/{variant}`. Its display shape differs from the frozen 3D shape; the gateway adapts it.
- **Artiko API** (`artiko-api/openapi.yml`, the new team's backend): `GET /api/v1/works`, `POST /api/v1/works` multipart with `proof[]`, `GET /api/v1/artists/{id}/museum`, `POST /api/v1/scan/image` returning `human_proven | artiko_work | known_work | ai_made | unknown`, Better Auth JWT. No LiDAR, no QR, no scan session. Compatibility is kept through an adapter, see [API-INTEGRATION.md](API-INTEGRATION.md).

## Renaming LOVA → KANTO

Scope of the rename in this session: the frontend wordmark, page titles, aria labels, interface copy, the motion-lab storage key, the frontend README and docs, and the root README title. The repository name, Git branches, issue numbers and the append-only session log keep their historical names. "Lova" remains in cultural copy where it means heritage.
