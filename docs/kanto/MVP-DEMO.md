# MVP demo — KANTO frontend

The demo path, what each step really does, and what is simulated. Branch `feature/kanto-frontend`. Verified on 2026-11-22 in headless Chrome 1440×900 and 390×844 with the in-browser mock (`VITE_API_MODE` unset): the whole path below ran without a console error (`scratchpad` script `demo.js`), and the unit suite reports 30 files, 138 tests.

## Run it

```sh
nvm use                                  # Node 22
npm ci
npm run dev -w apps/frontend             # http://localhost:5173
```

Local-only assets (gitignored) make the demo complete: `apps/frontend/public/media/` (paintings, valiha, the three CC0 models) and `apps/frontend/public/fonts/licensed/`. Without them the app shows its missing-media states and OFL fonts.

Demo accounts (mock only, stored in this browser):

| Account                | Password          | Role                                                 |
| ---------------------- | ----------------- | ---------------------------------------------------- |
| `visiteur@kanto.demo`  | `kanto-demo-2026` | Contributor, owns four deposits in every state       |
| `relecture@kanto.demo` | `kanto-demo-2026` | Reviewer and administrator, owns the published works |
| `atelier@kanto.demo`   | `kanto-demo-2026` | Second contributor (corrections requested)           |

"Réinitialiser les données de démonstration" (footer of `/mon-espace`) reseeds everything and keeps the current account signed in.

## Legend

- **Real**: works in the browser with no backend involved, or against the frozen contract once the gateway exists.
- **Mock**: runs on `lib/api/mock`, persisted in `localStorage`; the screen shows "Données de démonstration".
- **Simulated**: a result that pretends nothing: advisory signals computed from the record itself, a provenance record with no transaction, labelled on screen.
- **Absent**: not built; the UI says so.

## What is real, simulated or absent

| Capability                                                                     | Status                           | Detail                                                                                                                                                                  |
| ------------------------------------------------------------------------------ | -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| AI-assisted analysis, AI-generated detection, coherence, provenance, duplicate | Simulated                        | Deterministic signals computed from the record; labelled "Service de démonstration". CONTENT-05a/05b are the real services behind two of them, outside this repository. |

| LiDAR capture                                                                  | Absent in the browser, by design | Capture happens in the native iPhone app; the web pages pair, follow and transfer.                                                                                      |
| Scan session API                                                               | Absent                           | Frontend proposal in docs/API-INTEGRATION.md §4; mock only.                                                                                                             |
| Admin interfaces                                                               | Mock                             | Outside the MVP scope of docs/product/MVP.md, built as P1 behind the `reviewer` permission.                                                                             |
| Rooms 03 and 04 content (series, film, audio label)                            | Absent                           | Rights-cleared media needed.                                                                                                                                            |
| Gateway mode                                                                   | Wired, untested                  | `VITE_API_MODE=gateway` and `GATEWAY_URL`; no gateway exists yet.                                                                                                       |

## Known limits before the rehearsal

- Headless SwiftShader renders the WebGL room at a few frames per second, so the camera travelling and the GSAP arrival of the wall text take far longer than on a GPU. Check the room on the demo laptop and a phone (3D-05b) before the rehearsal; the photographic room (`?rendu=photo`) is the fallback.
- Prettier flags `eslint.config.mjs` as before this session (endy-rkt-17 baseline).
- Mock data lives in the presenter's browser: do the run-through once on the demo machine to warm the state, and keep the "Réinitialiser" action in mind.
- The scan pairing between a real iPhone and the laptop needs the proposed session API; in the demo, play the phone in a second tab or window of the same browser.
